**(2) Static-Dynamic Misalignment as Fundamental Constraint**: Capacity constraints are inherently sequential and state-dependent. Any attempt to encode them into static pairwise biases—even through sophisticated pseudo-dynamic proxies like residual demand pressure or angular neighborhood clustering—introduces noise that disrupts the decoder’s learned policy. The decoder already handles feasibility dynamically; static heuristics must focus exclusively on geometric and combinatorial guidance.

**(3) Statistical Rigidity as Performance Gatekeeper**: The LEHD decoder functions as a fixed sensory system with strict expectations about the scale, distribution, correlation structure, and orthogonality of heuristic inputs. Decorrelation (Gram-Schmidt, ZCA whitening), untrained adaptive fusion, or distributional shifts—even when theoretically sound—consistently degrade performance because they violate these implicit statistical contracts.

These principles collectively establish that **no further progress is possible within the static, pre-computed heuristic framework**. The frontier now lies unequivocally in architectural co-design that enables true joint trainability while respecting the decoder’s learned expectations. **(a) End-to-End Trainable Geometric Embedding**: Replace classical MDS with a lightweight, differentiable module (e.g., contrastive encoder or GNN) that is trained *jointly* with the LEHD decoder to produce angular representations optimized for routing performance—not geometric accuracy per se, but functional equivalence in supporting route coherence. **(b) Dynamic Bias Modulation with Real-Time State Conditioning**: Redesign the attention mechanism to accept real-time, differentiable bias adjustments conditioned on decoding state (current node, residual capacity, visited set summary). Standalone heuristic functions operating outside the LEHD training loop cannot achieve the necessary co-adaptation.
