    distribution of bin remainders. Statistical moments (mean, variance, skewness)

    set of candidate common sizes via parametric modeling. This eliminates reliance
    on fixed fractional relationships and instead generates multiplier sets that
    reflect the emergent structure of the current instance, while maintaining
    statelessness across instances.

    best-fit and multiple-fit components, but replaces the static learned embeddings

    best_fit_component = -feasible_post_caps  # Higher score for less remaining space

    feasible_scores = multiple_fit_weight * multiple_fit_score + best_fit_weight * best_fit_component
    
    # Assign the calculated scores to the correct positions
    scores[feasible_bins] = feasible_scores
    
    return scores
