def priority(item: float, bins_remain_cap: np.ndarray) -> np.ndarray:

    Priority heuristic implementing a lightweight, within-call instance-type classifier
    that uses real-time bin state statistics to dynamically select among pre-optimized

    most suitable heuristic strategy without violating stateless constraints.

    dynamic common-size generation from the parent solution while incorporating

        bins_remain_cap: NumPy array of remaining bin capacities

    post_placement_caps = bins_remain_cap - item
