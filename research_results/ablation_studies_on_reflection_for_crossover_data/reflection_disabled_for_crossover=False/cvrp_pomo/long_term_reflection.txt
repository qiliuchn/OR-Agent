The convergence of evidence from ten rigorous experiments—including the most recent five—has not only reaffirmed but sharpened the foundational thesis: **static heuristics in the POMO framework for CVRP are fundamentally bounded**, with a hard performance ceiling empirically stabilized at ~68.78 across diverse instance scales (n=200 to 1000). This ceiling is not a transient artifact of implementation but a structural limitation arising from the inability to condition on decoding state (vehicle load, visitation mask), which creates an irreducible gap between static guidance and dynamic routing feasibility. Critically, all attempts to circumvent this limitation—whether through angular similarity (Exp #3), quantile-normalized demand compatibility (Exp #4), hybrid spectral-geometric fusion (Exp #5), adaptive depot affinity (Exp #2), scalable Nyström approximations (Exp #1, #6–#9), or pseudo-learned modules like GNNs and MLPs with random weights (Exp #4, #10)—either matched the ceiling without surpassing it or regressed, confirming that **no static signal can compensate for dynamic state blindness**.

Three interlocking principles now define the optimal static heuristic configuration with near-certainty: (1) **Spectral fidelity via exact normalized graph Laplacian eigendecomposition** (using torch.linalg.eigh) is non-negotiable; even theoretically sound approximations (e.g., demand-stratified Nyström) degrade topological coherence and hurt large-instance performance. (2) **Demand compatibility must be continuous, differentiable, and ratio-based**, with squared absolute deviation (|demand_i/demand_j - 1.0|²) consistently outperforming linear penalties, log-ratios, Wasserstein distances, rank-based quantile mappings, or untrained learned embeddings—all of which either lose essential demand relationship information, introduce gradient pathologies, or inject noise when not properly trained. (3) **Numerical calibration is precise and fragile**: depot bias must be +0.1 total (not per direction), clamping ranges must be [-5,5] for n≤1000, and diagonal masking is mandatory; deviations cause consistent 2–4 point regressions.

Notably, the repeated achievement of the 68.78 score across Experiments #1, #3, #4, #6, #7, #8, #9, and #10—despite divergent heuristic innovations—reveals a deeper truth: **the static paradigm has converged to its global optimum**. Marginal gains are no longer possible through feature engineering; instead, any deviation from the proven triad (exact spectral + squared demand ratio + calibrated depot bias) incurs performance cost. This validates the methodological insight that **robustness and gradient stability outweigh theoretical elegance**: conceptually appealing additions (angular sectors, Delaunay adjacency, entropy-based depot incentives, learned compatibility embeddings without context-aware training) actively harm performance by disrupting the delicate equilibrium between global topology and local demand homogeneity.

Three persistent challenges remain insurmountable in isolation: (1) **Dynamic state blindness**—the root cause of the performance ceiling; (2) **Scalability fragility**—full eigendecomposition becomes computationally prohibitive beyond n=1000; and (3) **Instance rigidity**—optimal parameters (depot weight, clamp range) require manual tuning across data distributions. However, a unified solution path now emerges with greater clarity: **architectural co-design that embeds lightweight, differentiable spectral approximation within a context-aware decoder**. Specifically, future work must: (1) Develop a POMO decoder extension that accepts (load, mask) as inputs and uses a lightweight gating mechanism to modulate the static attention bias *during* decoding, transforming heuristics from static maps into responsive co-pilots; (2) Co-train this module with a demand-informed, differentiable spectral backbone (e.g., using gradient-stabilized Nyström with landmark selection based on demand clusters) to achieve O(n log n) scalability without sacrificing eigenvector alignment; and (3) Replace handcrafted demand ratios with *learned* compatibility embeddings trained via contrastive objectives on actual route-level feasibility—but only within the context-aware framework where gradients can flow through real decoding trajectories.

The path forward is unequivocal: **abandon static heuristic refinement**. The 68.78 ceiling is not a target to beat but a boundary to transcend through architectural innovation. The next breakthrough will not come from better priors, but from smarter, adaptive systems that use spectral topology as foundational terrain while dynamically responding to the evolving state of the routing process.
