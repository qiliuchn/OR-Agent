Recent experiments confirm that carefully balanced static heuristics—combining inverse distance, Clark-Wright savings, demand compatibility, and adaptive depot-proximity weighting—yield strong empirical performance, especially when using rank-based dynamic adjustments rather than fixed weights. However, the persistent performance gap on large-scale instances (e.g., 1000 nodes) reinforces that static priors fundamentally lack state-awareness of residual capacity and partial route context. Attempts to add complexity without true adaptivity degrade performance, highlighting the fragility of hand-crafted rules. The key insight is that effective heuristics must be both lightweight and differentiable, enabling integration with decoding states like vehicle load and visitation masks. Future work should prioritize end-to-end learnable attention biases trained via high-quality rollouts, moving beyond static designs toward dynamic, context-sensitive guidance that preserves vectorization and symmetry. Empirical validation on small instances remains essential to avoid implementation pitfalls before scaling.
