The latest experiment reinforces that heuristic effectiveness in ACO for MKP hinges on simplicity, bottleneck awareness, and robust slack modulation—not adaptive complexity. The failure of beta-distribution-based reference points confirms that elaborate offline modeling introduces instability, especially on larger instances, whereas a fixed reference (0.45) provides consistent, generalizable performance. This validates the core principle: static heuristics excel when grounded in interpretable, global instance statistics like min-ratio (prize-to-weight across constraints) and slack relative to a stable reference. Key successful patterns include softplus transformation for numerical stability, sparsification to focus selection, and median-based temperature scaling. However, a hard ceiling persists—static heuristics cannot adapt to dynamic construction states like residual capacity, limiting scalability. This reaffirms that the next breakthrough requires minimally invasive statefulness: augmenting the proven static framework with real-time feasibility signals (e.g., current load) without disrupting ACO’s probabilistic coherence. Future work must prioritize hybrid designs where the static min-ratio heuristic is multiplicatively adjusted by online slack, guided by targeted hyperparameter tuning around the 0.45 reference rather than complex estimation. The path forward is clear: preserve the robust static core, then layer lightweight, coherent dynamic feedback to overcome the adaptability barrier.
