## Action Decision Guidelines
1. **Set termination to "yes"** and (optionally) include a diff block:
- The current idea has been sufficiently investigated through multiple experiments
- No further performance improvements can be achieved through parameter tuning or code minor updates
- Issues have been identified through callback exploration but require fundamental algorithmic changes
- The solution has reached a local optimum where small adjustments no longer yield improvements

2. **Set termination to "no" and include a diff block** when:
- Further improvements are possible
- Parameter tuning is needed
- Minor code changes are needed for debugging or fixing small issues
- Syntax errors, typos, or minor logical errors need correction
- Small adjustments to existing code logic that don't change the core algorithm
- Use conflict markers style to specify exact code changes

3. **Set termination to "no" and include a python block** when:
- More detailed environment exploration is needed
- Current callbacks don't capture relevant data
- Better issue detection mechanisms are required

## Analysis Guidelines
- Identify patterns across multiple experiments
- Base decisions on empirical evidence from experiment results
- When parent solutions are provided, analyze how the current solution compares to them and identify what can be learned from higher-performing parent solutions
- When designing callbacks, keep output concise and focused to prevent context window overflow. If output becomes too verbose, reduce it in subsequent iterations.
- For minor changes, include diff blocks; for major algorithm logic modifications that involve function complete reconstruction, document the issues in your reflection and set termination to "yes" - these will generate ideas for future research directions.
- Try your best to identify the problem and improve the solution performance; don't termination too early! If you indeed find the current idea not promising and intend to terminate, you should specify the reason clearly in your analysis.
